# Dota 2 Modding

Открытые данные для разработки кастомных игр Dota 2, снятые из самой игры:
исходные дампы в JSON, готовые аннотации для редактора и сайт для просмотра.

Сайт: https://withvoidwithin.github.io/dota2_modding/

## Структура

```
data/                 исходные дампы (JSON), по разделам
  index.json          список наборов данных — по нему строится сайт
  vscripts/           Lua API серверной и клиентской VM; формат — README в папке
annotations/
  lua/                определения LuaCATS для EmmyLua
    shared/           что есть на сервере и клиенте
    server/, client/  что есть только на одной стороне
site/                 сайт GitHub Pages: статический, без сборки
.github/workflows/    публикация сайта вместе с data/ и annotations/
```

Каждый набор данных — папка в `data/` и запись в `data/index.json` с полем
`kind`, по которому сайт выбирает, как его показывать.

## Аннотации Lua

Подключаются как библиотека в `.emmyrc.json` проекта (проверено на EmmyLua):

```json
{
  "workspace": {
    "library": ["<путь к репозиторию>/annotations/lua"]
  }
}
```

Подключать все три папки вместе: код способностей и модификаторов выполняется
и на сервере, и на клиенте. Класс, который есть на обеих сторонах, объявлен в
`shared/`; его методы, которые есть только на одной, — в частичном объявлении
того же класса в `server/` или `client/`. Такие методы ещё и помечены в
описании: «Server only.» / «Client only.».

Чего движок не сообщает, того в аннотациях нет: класса у `handle`, имён
половины параметров, обработчиков, которые пишет аддон (`OnSpellStart`,
`GetModifier*`).

## Версии

Номер сборки игры — в поле `build` каждого дампа. Ключи в JSON отсортированы,
поэтому `git diff` между коммитами показывает, что изменилось в API после
патча.

## Локальный просмотр сайта

```bash
python -m http.server 8000
```

В корне репозитория, затем открыть http://localhost:8000/site/.
